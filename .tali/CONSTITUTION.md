# La Constitución — Principios de Gobernanza del Framework

Las siguientes leyes son inmutables. Cualquier Pull Request que las viole
será rechazado automáticamente por el sistema.

---

## 1. Framework-First
Este repositorio contiene una aplicación real y ejecutable. El framework
no la reemplaza: orquesta y gobierna su ciclo de desarrollo.

## 2. Ciclo obligatorio: Analyze → Plan → Specify → Execute → Verify → Document
Ninguna línea de código puede integrarse al repositorio sin haber
completado estas seis fases de forma secuencial antes del merge.

## 3. Spec-First
Sin una especificación técnica previamente aprobada por el Planner,
la implementación está estrictamente prohibida.

## 4. Estrategia Cognitiva de Modelos
- **Thinking** — Planificación, arquitectura, especificación
- **Balanced** — Ejecución, desarrollo, documentación
- **Fast** — Verificación, validación sintáctica, QA

## 5. Engram — Memoria Persistente Activa
Las decisiones arquitectónicas y la causa raíz de bugs deben
persistirse proactivamente y compartirse entre todos los agentes.

## 6. Stack-Agnostic
El framework es independiente del lenguaje, plataforma o vendor
de IA subyacente. Se adapta a cualquier entorno tecnológico.
